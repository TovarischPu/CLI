# Dependency Graph Visualizer (Maven)

## Общее описание

CLI-приложение для визуализации графа зависимостей пакетов Maven.
На первом этапе реализован минимальный прототип: парсинг аргументов
командной строки, валидация параметров и вывод конфигурации.

## Настройки

| Параметр        | Описание                                        |
|-----------------|-------------------------------------------------|
| `--package`     | Имя анализируемого пакета (обязательно)         |
| `--source`      | URL репозитория или путь к тестовому файлу      |
| `--test-mode`   | Режим работы с локальным тестовым репозиторием  |
| `--ascii-tree`  | Вывод зависимостей в виде ASCII-дерева          |
| `--max-depth`   | Максимальная глубина анализа (по умолчанию 5)   |
| `--filter`      | Подстрока для фильтрации пакетов                |

## Этап 1. Минимальный прототип с конфигурацией

### Цель этапа
Создать минимальное CLI-приложение, сделать его настраиваемым через аргументы командной строки и реализовать валидацию входных данных.

### Реализованный функционал
Приложение принимает 6 настраиваемых параметров и выводит их в формате `ключ = значение` при запуске:

| Параметр | Тип | Описание |
|---|---|---|
| `--package` | `str` | Имя анализируемого пакета (обязательно) |
| `--source` | `str` | URL репозитория или путь к тестовому файлу (обязательно) |
| `--test-mode` | `flag` | Режим работы с локальным тестовым репозиторием |
| `--ascii-tree` | `flag` | Режим вывода зависимостей в виде ASCII-дерева |
| `--max-depth` | `int` | Максимальная глубина анализа зависимостей (по умолч. 5) |
| `--filter` | `str` | Подстрока для фильтрации пакетов |

### Обработка ошибок
Реализована кастомная валидация для всех параметров. При некорректном вводе программа не падает с исключением (Traceback), а выводит понятное сообщение об ошибке в `stderr` и завершается с кодом возврата `2`.

## Этап 2. Сбор данных

### Цель этапа
Реализовать основную логику получения данных о прямых зависимостях пакета Maven для их дальнейшего анализа. 

### Реализованный функционал
1. **Формат пакетов**: Строгая поддержка формата Maven `groupId:artifactId:version`.
2. **Формирование URL**: Автоматический расчет корректного пути к файлу `.pom` в указанном репозитории на основе координат пакета.
3. **Парсинг XML**: Извлечение прямых зависимостей из тега `<dependencies>`. Реализована устойчивая обработка как файлов с объявленным пространством имен (`xmlns`), так и без него.
4. **Фильтрация**: Игнорируются служебные блоки (например, `<dependencyManagement>`), извлекаются только реальные прямые зависимости.

### Соблюдение ограничений
- **Запрет на сторонние библиотеки**: Для сетевых запросов используется только стандартный модуль `urllib.request`, для парсинга XML – `xml.etree.ElementTree`. Менеджеры пакетов (вроде `mvn`) не вызываются.
- **Качество кода**: Соблюдены все правила репозитория (docstring вместо комментариев, длина строк ≤ 80 символов, функции ≤ 40 строк, отсутствие магических чисел).
